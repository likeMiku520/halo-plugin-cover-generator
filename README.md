# 封面生成器(Cover Generator)

一款 Halo 2.x Console 插件:在 Console 内为文章生成封面图,一键保存为站点附件并绑定文章封面。纯前端渲染(标题以矢量路径内嵌,零字体依赖),无需任何第三方图像服务。

- 作者:fufu大王 · [blog.fufu520.cn](https://blog.fufu520.cn)
- 许可:GPL-3.0
- 当前版本:1.4.0（[更新日志](./CHANGELOG.md)）
- 环境要求:Halo `>=2.26.0`

## 功能

**工作台(Console 独立页 `/console/cover-generator`)**

- 多分辨率画布:9 档预设,从「横版 OG 1.91:1」到「正方形 1:1」「竖版 4:5 / 3:4」「故事 9:16」,默认 1200×630;换比例不会丢内容
- 实时预览:左控制面板 + 右预览窗,任意输入即时联动,预览按当前分辨率等比缩放
- 标题排版双模式:**左右分缝**(两段共用字号并按长度取齐,中缝间距可调)与**整块排版**(自动换行、整块居中),两种模式各自独立成文,切换互不覆盖
- 元素自由定位:Logo / 标题 / 副标题 / 水印都能用方向键微调(Shift 加速),也能用「水平 / 垂直 / 大小」三条拖动条精调(拖动条与数值框双向联动);每个元素带独立大小倍率
- 文字排版:标题 / 副标题 / 水印各自可调**字间距**、**弯曲度**(圆弧文字)、**旋转**,并可切换**横排 / 竖排**;全部滑杆都带名称
- 元素层级:全部元素(含自定义元素)共用一套图层顺序,可上移/下移一层
- 自定义元素:可追加**图片**(上传 / 附件库 / 链接)、**文字**(任意颜色、加粗)、**SVG 图标**(Halo 内置 Iconify 选择器:图标集浏览 + 检索 + **取色** / 粘贴源码 / 上传 .svg / 直链),支持缩放、调层级与圆形裁剪,上限 12 个
- 字号自适应:超宽自动缩字号(下限 64px),仍超宽水平压缩;基准字号 100–210 手动可调
- 副标题:34px 基准、0.3em 字距、两侧装饰线、轻投影,超宽整体压缩
- 渐变系统:24 套预设(5 组)+ 自定义起止色/角度,支持粘贴 CSS `linear-gradient(...)` 直接解析
- 背景系统:渐变,或**图片**背景(上传 / 附件库 / 链接),图片上可加 0–60% 压暗遮罩保证标题可读
- Logo 管理:圆形裁剪 + 双层柔影;默认 Logo / Halo 自带附件入口(上传 / 附件库 / 链接)/ 隐藏
- SVG 导出:文字转矢量 path、Logo 与自定义图片 Base64 内嵌的自包含 SVG,文件名取标题净化
- PNG 导出:canvas 栅格化,尺寸跟随当前分辨率
- 域名水印:文案(默认值取插件设置,空则不渲染),位置可调
- 保存为附件:栅格化 PNG 上传 Halo 附件库,存储策略/分组按设置,成功提示含附件链接
- 绑定文章封面:文章选择器检索选定文章,写入封面;乐观锁冲突自动重试一次
- 插件设置:Console 可视化表单,附件分组与存储策略用 Halo 官方选择器直接选,不必手写资源名
- 本地持久化:工作台输入自动存 localStorage,刷新/重开不丢;存档损坏整体回退默认;旧档自动迁移并补齐新字段

**文章列表入口**

- 文章列表操作菜单「生成封面」:一键跳转工作台并自动预选该文章(带回文章与标题),选好样式后「保存并绑定」即可

**体验增强**

- 渐变「随机」换色:从预设中随机应用且不与当前重复
- 自定义字体:设置字体附件 URL 即可替换内置字体;加载失败自动降级并禁用导出
- 复制 SVG 源码 / PNG @2x 高清导出(PNG 尺寸随分辨率与倍率推导)
- 全键盘可达:元素列表选中后可用方向键微调,文章检索与 PNG 尺寸菜单支持方向键/Enter/Esc,焦点环与对比度按 WCAG AA 校准

## 安装

- **应用市场**:待上架。
- **手动安装**:下载 Release 中的插件 JAR(或自行 `./gradlew build`,产物在 `build/libs/`),在 Console「插件 → 安装」上传安装并启用。

环境要求:Halo `>=2.26.0`(UI 运行时依赖 `@halo-dev/ui-shared` 宿主全局与 2.26 加载器契约,已在 2.26.x 实测)。

## 使用

- **工作台**:Console 侧边栏打开「封面生成器」,先选分辨率,再填标题/副标题/渐变/Logo/水印;元素在「元素」列表里点选后,用方向键微调或在面板输入精确位置与大小;完成后可「下载 SVG」「下载 PNG」「复制 SVG」「保存到附件」,或配合文章选择器「保存并绑定」。
- **文章列表入口**:文章列表某篇的「更多」操作菜单 →「生成封面」,自动跳转工作台并预选该文章,选好样式后「保存并绑定」即可。
- **自定义元素**:「元素」面板底部先选类型(文字 / 图片 / SVG 图标),再执行添加;图片用 Halo 自带的附件入口(上传 / 附件库 / 链接);SVG 用 Halo 内置的 Iconify 选择器(可浏览图标集、可检索、**可取色**),也可粘贴源码、上传 .svg 或直链导入。

## 插件设置

Console「插件 → 封面生成器 → 设置」:

| 字段 | 默认值 | 说明 |
|---|---|---|
| 默认水印文案(`watermark`) | 空 | 工作台初始水印,空 = 不显示水印 |
| 默认 Logo 图片(`logoUrl`) | 空 | 工作台初始 Logo(选附件);空 = 初始隐藏 Logo |
| 自定义字体(`fontUrl`) | 空 | 字体附件 URL;空 = 使用内置抖音美好体 |
| 附件存储策略(`attachmentPolicy`) | 空 | 用 Halo 自带的选择器挑选;空 = 由 Halo 决定默认策略 |
| 附件分组(`attachmentGroup`) | 空 | 用 Halo 自带的选择器挑选;空 = 不指定分组 |

> 附件分组与存储策略保存的是资源名(`metadata.name`),选择器会列出站点上真实存在的分组与策略,不再需要手写。若保存到附件时提示分组不存在,插件会按该分组名自动创建后重试一次(需要附件管理权限)。

## 开发

环境要求:JDK 21、Node.js ≥ 22.12、pnpm、Docker(DevTools 模式运行 Halo 使用)。

已在 Halo 2.26.x 验证;manifest 声明 `>=2.26.0`,与实际验证范围一致。

```bash
# 安装前端依赖
cd ui && pnpm install

# 启动本地 Halo 开发实例(Console: http://localhost:8090),自动加载本插件
./gradlew haloServer

# 质量门禁(eslint + oxlint + vue-tsc + vitest,0 警告)
pnpm quality

# 构建插件 JAR(产物:build/libs/plugin-cover-generator-*.jar)
./gradlew build
```

**版式目视核对**:改排版算法后,除了跑单测,建议生成一组快照看一眼实际观感:

```bash
# 1) 产出代表性版式的 SVG 到 ../.visual-out(该目录已 gitignore)
cd ui && npx vitest run src/lib/visual.output.spec.ts

# 2) 栅格化为 PNG(纯 Pillow 实现的极简光栅器,只为看版式,不追求像素级还原)
cd ../.visual-out && python ../scripts/render_svg.py 01-split-default 02-split-uneven 03-flow
```

数值不变量由 `svgBuilder.spec.ts` 的断言守住(中缝对齐、两段等字号、触底压缩不溢出),脚本只负责产出可看的图。

## 字体授权

插件内置「抖音美好体」(Bold)作为默认字体。该字体由字节跳动官方声明**免费商用**(含商业场景),本插件按其授权条款随包再分发;具体授权范围以官方发布页最新说明为准。

字体文件随插件 JAR 的静态资源分发(不经 UI 打包),运行时经 `/plugins/cover-generator/assets/fonts/**` 按需加载。
